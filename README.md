# Ectools: versões

Aqui ficam só as versões prontas do **Ectools** (ferramenta para o Ragnarok, servidor Aetheria).
O código do programa não fica aqui.

- **Primeira vez:** baixe o `Ectools.zip` da versão mais nova em [Releases](../../releases/latest), extraia a pasta e abra o `Ectools.exe`.
- **Depois:** o Ectools avisa sozinho quando sai uma versão nova. É só clicar em **Atualizar**.
